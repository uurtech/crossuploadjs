Upload from your phone into this form

This is an ordinary form with the CrossUpload widget attached. Click Upload a file, then pick a file on this computer or scan the QR code with your phone. Your phone must be able to reach this server (same Wi-Fi, or set PUBLIC_URL).

No files yet

What happens here

  1. The widget asks POST /demo/session for an upload session. In your app this is your backend calling POST /v1/sessions with SECRET_KEY.
  2. Files go straight to this server, the real type is read from the bytes, and accepted file IDs land in the hidden attachment_ids field.
  3. On submit, the form handler checks every ID again on the server (GET /v1/files/:id).
